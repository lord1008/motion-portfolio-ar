# ملف أعمال موشن عربي

موقع ثابت باللغة العربية، مستوحى من إيقاع وتخطيط الموقع المرجعي الذي أرسلته. الرسوم المتحركة الحالية أمثلة أصلية تجريبية، وليست أعمالك الفعلية. يمكن نشره على GitHub Pages دون أدوات بناء.

## قبل إرسال الرابط إلى العملاء

1. افتح `assets/site-config.js` وأضف اسمك، بريدك، رقم واتساب بصيغة دولية بدون علامة `+`، وروابط حساباتك إن أردت.
2. افتح `assets/projects.js` وغيّر عنوان كل مشروع ووصفه وتصنيفه. لإضافة صورة، ضعها في `assets/` واكتب مثلاً `image: "assets/project-01.jpg"`. لإضافة فيديو، استخدم `video: "assets/project-01.mp4"`. ويمكن إضافة `poster` لصورة الغلاف و`link` لرابط العمل الكامل.
3. احذف النماذج التي لا تريد عرضها. سيُبنى المعرض تلقائياً من المشاريع الموجودة في القائمة.
4. راجع نصوص `index.html` و`about.html` و`contact.html` لتطابق تخصصك وأسلوبك.

## النشر على GitHub Pages

ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub (بحيث يكون `index.html` في الجذر)، ثم افتح إعدادات المستودع **Settings → Pages**. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واحفظ. سيظهر رابط الموقع في صفحة Pages بعد اكتمال النشر. الملف `.nojekyll` يضمن تقديم ملفات HTML/CSS/JS كما هي.

إذا كان اسم المستودع `motion-portfolio-ar` فصيغة الرابط ستكون عادةً `https://USERNAME.github.io/motion-portfolio-ar/` بعد استبدال `USERNAME` باسم حسابك. الروابط داخل الموقع نسبية لتعمل مع مسار المستودع.

## الملفات

- `index.html`: الصفحة الرئيسية والمعرض.
- `about.html`: النبذة.
- `contact.html`: التواصل.
- `project.html`: صفحة تفاصيل العمل.
- `assets/styles.css`: التنسيق والحركة والاستجابة للشاشات.
- `assets/site-config.js`: الاسم وبيانات التواصل.
- `assets/projects.js`: المشاريع والرسوم التجريبية.
- `assets/app.js`: بناء المعرض وصفحات الأعمال والساعة.
